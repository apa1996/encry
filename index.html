📚 Learn the important terms

What is plaintext?

Plaintext is the original message that people can read, such as “HELLO”.

What is encryption?

Encryption is the process of changing readable information into coded information so that it cannot easily be understood by an unauthorized person.

What is ciphertext?

Ciphertext is the coded result produced after encryption.

What is a key?

A key is information used by an encryption algorithm to encrypt or decrypt a message. In this demo, the Caesar key is a number; the AES demo uses a password-derived key.

What is decryption?

Decryption changes ciphertext back into the original readable message using the correct key.
