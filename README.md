# encry
An interactive web-based Encryption &amp; Decryption project using HTML, CSS, and JavaScript. Demonstrates Caesar Cipher and AES-256 encryption with real-time message encryption, decryption, and password-based security. Developed by Aparup Sarkar for educational purposes.
# 🔐 Encryption Classroom Demo

An interactive website demonstrating how Encryption and Decryption work using HTML, CSS and JavaScript.

## 👨‍💻 Developer
**Aparup Sarkar**

## 🚀 Features
- Caesar Cipher Encryption
- Caesar Cipher Decryption
- AES-256-GCM Encryption
- Password-based Decryption
- Interactive Learning Interface
- Responsive Design

## 🛠 Technologies Used
- HTML5
- CSS3
- JavaScript
- Web Crypto API

## 📖 How to Use
1. Enter your message.
2. Select an encryption key.
3. Click Encrypt.
4. View the encrypted message.
5. Click Decrypt to recover the original message.
